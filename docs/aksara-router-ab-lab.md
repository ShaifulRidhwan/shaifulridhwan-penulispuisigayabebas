# AKSARA | Evaluation Lab
Penanda aras enam kes sintetik untuk Bahasa Melayu Malaysia, falsafah, sains, kod, susulan konteks dan identiti. Jangan hantar sejarah peribadi pengguna.
Ujian CLI membandingkan Groq dan OpenRouter apabila kedua-duanya disediakan menggunakan credentials persekitaran sendiri. Cloudflare Workers AI ialah **native binding**, jadi ujian sebenar model GLM perlu dilakukan dalam Worker staging dengan kuota neurons yang jelas, bukan memalsukan API key.
Semak identiti (aku, bukan saya), ketepatan CAHAYA/GELAP, konteks multi-turn, masa first token, stream, quota, dan fallback. Keyword coverage bukan ukuran keseluruhan kecerdasan.
