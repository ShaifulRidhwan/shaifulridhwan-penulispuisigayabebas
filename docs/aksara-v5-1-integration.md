## Delivered changes

- Propagate router abort/deadline signals into Workers AI REST inference, preventing a timed-out or cancelled call from continuing alongside fallback inference. Existing GLM chat endpoint, capability policy, output guards and bounded retries remain authoritative.
- Align Workers AI readiness diagnostics with actual token whitespace validation.
- Let Chat continue when optional summarization times out; preserve cancellation of the whole user request. Existing history retrieval, saved summary and encrypted archive remain available.
- Classify provider HTTP/reason evidence into rate limited, misconfigured and unavailable states. Keep Ready distinct from Online and backend DNS/transport failure distinct from provider failure.
- Acknowledge Gemini Live peer close frames so OkHttp completes the handshake and invokes existing epoch-guarded reconnect recovery. Preserve Aoede, Malay instructions, token broker, audio routes and reconnect limits.
- Review the exact router fingerprint after the cancellation-only change. Replace an obsolete source-syntax assertion with an actual recorded-Voice request verifying primary-key use, zero chat-pool selection and exactly one inference. No identity/personality lock is removed.

## Reused architecture and boundaries

Android `WebBrainBridge` calls Netlify `bilik-antara` / `bilik-antara-stream`; it does not contain provider secrets or a replacement brain. The backend owns Context Manager, Brain/Identity, Thinking V3/V4, Intelligence V5, consistency/quality/evidence/recovery V6, model/capability registry, structured output, safe tools, data analysis, research workflow, vision diagnostics, prompt optimization, telemetry and infrastructure guards. Cahaya/Gelap are sent as actual request modes.

Workers AI text uses `@cf/zai-org/glm-4.7-flash`, through native `AI` binding or Netlify's REST bridge. It is already a normal fallback provider. Studio separately uses `@cf/black-forest-labs/flux-1-schnell` and `@cf/black-forest-labs/flux-2-klein-4b`; text is never routed to those image endpoints. The source already supports encrypted session history/context/drafts, controlled summarization, context selection, import/export, branching and receipt-based uploads. Memory remains OFF by default. Android explicitly denies media/private-context fallback; summary fallback denial must also be present in the deployed backend.

Creator/identity and ecosystem awareness reuse `bilik-antara-identity.js`, `aksara-reference-hub.js`, capability/model manifests and Studio awareness. No changing repository snapshot is embedded in an APK prompt. Knowledge and research outputs retain source/evidence boundaries. None of this proves every remote tool or model is live.

No game, literary, library, splash, login, terminal, Code Engine, SD-Turbo or avatar source changes. PR #292 remains independent. Existing CI automatically runs some protected-module checks; those are shared workflow results, not V5.1 retesting or modification instructions.
