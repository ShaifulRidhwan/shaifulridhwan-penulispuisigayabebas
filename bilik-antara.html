Ruang kecerdasan buatan Shaiful Ridhwan untuk berbual dan berfikir. Aku jawab santai, jujur, dan sedikit sindiran halus.

Sembang tidak disimpan pada peranti melainkan diaktifkan. Mesej dihantar kepada penyedia AI untuk dijawab. Mod Selidik mungkin menggunakan kuota carian tambahan.

Menyambung ke ruang kecerdasan… Menyemak sambungan ke backend Gemini. Sebentar lagi.

Prinsip keselamatan

  • API key tidak pernah berada di sisi pelayar. Halaman ini hanya menghubungi /.netlify/functions/bilik-antara — fungsi Netlify yang menyimpan key sebagai environment variable dan memanggil Gemini bagi pihak anda.
  • Model lalai: gemini-3.6-flash (model lalai yang dikonfigurasi). Boleh diatasi dengan GEMINI_MODEL. Soalan tentang Shaiful Ridhwan dijawab secara tempatan dari fakta awam yang disahkan — tanpa melalui Gemini.
  • Pada tier percuma Gemini, soalan mungkin digunakan Google untuk memperbaiki produk.

Format respons backend

{
  "mode": "live",
  "aiMode": "general",
  "reply": "jawapan",
  "quotes": [],
  "disclaimer": "...",
  "model": "gemini-3.6-flash"
}

Jika endpoint gagal, mesej ralat yang jelas dipaparkan bersama butang “Cuba sambung semula”.
