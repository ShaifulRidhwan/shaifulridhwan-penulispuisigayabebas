Nota idea dalam perbualan

    Semua soalan diurus secara automatik. Carian, pengiraan dan semakan hujah digunakan apabila perlu. Sejarah sesi hanya disimpan pada peranti dengan izin; mesej dan lampiran dihantar ke penyedia AI.

    Prinsip keselamatan

    • API key tidak pernah berada di sisi pelayar. Halaman ini hanya menghubungi /.netlify/functions/bilik-antara — fungsi Netlify yang menyimpan key sebagai environment variable dan memanggil Gemini bagi pihak anda.
    • Model lalai: gemini-3.6-flash, boleh ditukar melalui GEMINI_MODEL. Penaakulan, carian Google dan alat pengiraan dipilih secara automatik apabila diperlukan (boleh menambah kos). Soalan identiti penulis dijawab daripada fakta awam yang disahkan.
    • Pada tier percuma Gemini, soalan mungkin digunakan Google untuk memperbaiki produk.

    Format respons backend

    {
  "mode": "live",
  "aiMode": "general",
  "reply": "jawapan",
  "quotes": [],
  "disclaimer": "...",
  "model": "gemini-3.6-flash"
}

    Jika endpoint gagal, mesej ralat yang jelas dipaparkan bersama butang “Cuba sambung semula”.
