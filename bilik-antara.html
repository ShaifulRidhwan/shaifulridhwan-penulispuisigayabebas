Prinsip keselamatan

  • API key tidak pernah berada di sisi pelayar. Halaman ini hanya menghubungi /.netlify/functions/bilik-antara — fungsi Netlify yang menyimpan key sebagai environment variable dan memanggil Gemini bagi pihak anda.
  • Model lalai: gemini-3.8-flash (Flash paling pintar, stabil). Boleh diatasi dengan GEMINI_MODEL (cth: gemini-4-argon untuk penaakulan tertinggi, dengan kos & latensi lebih tinggi). Soalan tentang Shaiful Ridhwan dijawab secara tempatan dari fakta awam yang disahkan — tanpa melalui Gemini.
  • Pada tier percuma Gemini, soalan mungkin digunakan Google untuk memperbaiki produk.

Format respons backend

{
  "mode": "live",
  "aiMode": "general",
  "reply": "jawapan",
  "quotes": [],
  "disclaimer": "...",
  "model": "gemini-3.8-flash"
}

Jika endpoint gagal, mesej ralat yang jelas dipaparkan bersama butang “Cuba sambung semula”.
