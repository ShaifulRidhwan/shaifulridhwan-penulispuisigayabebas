Bilik Antara

“Jangan cari aku di hujung. Cari aku di antara. Sebab di situlah aku paling hidup.”

Tanya soalan tentang idea, hujah, petikan dan tafsiran novel. Setiap jawapan membezakan petikan sebenar, tafsiran munasabah dan catatan had — tiada petikan direka, tiada dakwaan tentang niat penulis tanpa bukti.

Mod demo aktif — AI sebenar belum disambungkan. Jawapan disusun oleh Pemandu Petikan Tempatan menggunakan petikan sebenar novel yang dibenamkan dalam halaman ini. Ia bukan model bahasa: ia tidak mencipta jawapan baharu, hanya memadankan soalan anda dengan petikan dan tema yang wujud. Untuk menyambung AI sebenar (Gemini API) melalui backend tanpa mendedahkan API key, buka bahagian “Cara menyambung AI sebenar” di bawah.

Cara menyambung AI sebenar & seni bina

Prinsip keselamatan

  • API key TIDAK boleh diletakkan dalam HTML/JS klien. Mana-mana key di sisi pelayan boleh dicuri sesiapa sahaja dengan melihat sumber halaman.
  • Halaman ini hanya menghubungi satu endpoint: /.netlify/functions/bilik-antara. Endpoint inilah yang menyimpan key sebagai environment variable terenkripsi dan memanggil model AI bagi pihak anda.
  • Laman ini dihos di Netlify, yang menyediakan Netlify Functions (serverless Node.js) dan environment variables terenkripsi — jadi platform boleh menyediakan backend dan menyimpan rahsia tanpa pelayan berasingan.

Apa yang boleh dibina terus (tanpa kos)

  • Seluruh UI sembang, keadaan memuatkan, ralat, soalan permulaan — fail ini sahaja.
  • Pemandu Petikan Tempatan (mod demo) dengan 40+ petikan sebenar novel dibenamkan.

Apa yang memerlukan perkhidmatan luaran + kos

  • Model AI sebenar: Gemini API (Google) — caj mengikut token jika melebihi kuota percuma. Kuota percuma wujud tetapi TIDAK tanpa had (had harian/RPM, reset tengah malam Waktu Pasifik; semak di AI Studio). Netlify Functions sendiri mempunyai tier percuma yang besar; kos utama ialah API model.
  • Untuk kualiti grounding yang tinggi, tambahkan teks penuh novel ke dalam fungsi (RAG) supaya AI memetik dengan tepat.

Langkah sambungan

  • 1. Letakkan bilik-antara.js bersama novel-kb.json ke dalam folder netlify/functions/ dalam repo laman (kedua-duanya mesti dalam folder yang sama). Tambah netlify.toml yang disertakan di root repo.
  • 2. Di dashboard Netlify → Site settings → Environment variables, tambah GEMINI_API_KEY (diperoleh dari Google AI Studio). Pilihan: GEMINI_MODEL (default gemini-2.5-flash; boleh tukar selepas mengesahkan ketersediaan & had kuota di AI Studio — jangan anggar kuota percuma tanpa had).
  • Privasi tier percuma: pada tier percuma Gemini, soalan & petikan yang dihantar mungkin digunakan Google untuk memperbaiki produk mereka. Fungsi hanya menghantar 5–7 petikan berkaitan (bukan keseluruhan manuskrip). Jika ini tidak diterima, aktifkan billing (Tier 1 berbayar) di Google Cloud.
  • 3. Deploy semula. Halaman ini akan mengesan endpoint secara automatik dan menukar badge kepada “AI Bersambung”.
  • 4. Sistem prompt dalam fungsi ini sudah menguatkuasakan: bezakan petikan/tafsiran/pendapat, larangan mereka petikan, dan larangan mendakwa niat penulis.

Format respons backend (dijangka)

{
  "mode": "live",
  "reply": "jawapan penuh dengan label lapisan",
  "quotes": [ {"text":"...","section":"AKAL — ..."} ],
  "disclaimer": "..."
}

Jika endpoint tiada (404) atau gagal, halaman ini secara automatik kembali ke mod demo dan memaparkan mesej ralat yang jelas — ia tidak pernah berpura-pura AI berfungsi.
