Prinsip keselamatan

  • API key tidak pernah berada di sisi pelayar. Halaman ini hanya menghubungi satu endpoint: /.netlify/functions/bilik-antara — fungsi Netlify yang menyimpan key sebagai environment variable terenkripsi dan memanggil Gemini bagi pihak anda.
  • Model lalai: gemini-3.6-flash (boleh diatasi dengan GEMINI_MODEL). Soalan tentang Shaiful Ridhwan dijawab secara tempatan dari fakta awam yang disahkan — tanpa melalui Gemini — bagi mengelakkan rekaan biodata peribadi.
  • Pada tier percuma Gemini, soalan mungkin digunakan Google untuk memperbaiki produk. Jika tidak diterima, aktifkan billing di Google Cloud.

Format respons backend

{
  "mode": "live",
  "aiMode": "general",
  "reply": "jawapan",
  "quotes": [],
  "disclaimer": "...",
  "model": "gemini-3.6-flash"
}

Jika endpoint gagal, mesej ralat yang jelas dipaparkan bersama butang “Cuba sambung semula” — halaman tidak pernah berpura-pura AI berfungsi.
